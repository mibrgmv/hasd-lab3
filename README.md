# Лабораторная 1: бинарное кодирование датасета hits_v1

Собственный колоночный формат **HBC1** для датасета Яндекс.Метрики `hits_v1` (ClickHouse),
кодер и декодер на Go без сторонних библиотек.

|               |                                                   |
|---------------|---------------------------------------------------|
| Исходный TSV  | 7 784 МБ, 8 873 898 строк, 133 колонки            |
| HBC1          | **949.6 МБ (12.20%, в 8.2 раза меньше)**          |
| Кодирование   | 35–50 с (Apple M2, 8 ядер)                        |
| Декодирование | ~11 с                                             |
| Проверка      | sha256 декодированного файла совпадает с исходным |

## Запуск

```bash
mkdir -p data
curl -o data/hits_v1.tsv.xz https://clickhouse-datasets.s3.yandex.net/hits/tsv/hits_v1.tsv.xz
xz -dc data/hits_v1.tsv.xz > data/hits_v1.tsv

go build -o bin/hits ./cmd/hits
./bin/hits encode -o data/hits_v1.hbc data/hits_v1.tsv   # печатает таблицу по колонкам
```

Проверка, что датасет восстанавливается без изменений:

```bash
shasum -a 256 data/hits_v1.tsv
./bin/hits decode data/hits_v1.hbc | shasum -a 256
# оба раза: 4e9bc368ff3c139131dee42a63d68e6d8069641303b304c133540dc1e56c8e43

./bin/hits decode data/hits_v1.hbc | cmp - data/hits_v1.tsv && echo "файлы идентичны"
```

Прочее:

```bash
go run ./cmd/profile data/hits_v1.tsv   # статистика по колонкам датасета
go test ./...                           # тесты
```

## Как устроено

Каждая колонка кодируется независимо, в отдельный блок:

```
"HBC1" | число строк | оглавление: имя, тип, размер блока каждой колонки | блоки колонок
```

Кодер читает файл дважды. Первый проход собирает статистику колонки, затем для неё
вычисляется точный размер каждого варианта и выбирается минимальный, второй проход пишет данные.
Варианты:

- `const` – одно значение на всю колонку;
- `plain` – `значение − минимум` (для строк: длина + байты);
- `delta` – разность с предыдущим значением;
- `dict` – номер в отсортированном словаре различных значений; словарь строк хранится с front
  coding, словарь чисел – разностями соседних значений;
- любой из них можно дополнить RLE (серия одинаковых значений записывается один раз с длиной).

Числа пишутся классами ширин: 0–2 бита метки и значение в одной из ≤4 ширин, подобранных под
колонку. Подробное описание и обоснование – в отчёте.

## Cтруктура

```
cmd/hits            encode / decode
cmd/profile         статистика по колонкам датасета
internal/codec      формат HBC1: выбор способа (plan в intcol.go и bytescol.go), классы ширин (bits.go)
internal/tsv        нарезка TSV на строки и поля без копирования, параллельный обход колонок
internal/textval    разбор и печать чисел и дат (только каноничная запись)
internal/schema     схема hits_v1 (schema.txt)
reports/            profile.txt – статистика датасета; encode_v1.txt, encode_v2.txt – результат по колонкам
```
